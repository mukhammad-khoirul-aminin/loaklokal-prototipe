# LoakLokal - Platform Jual Beli Barang Bekas & Donasi (Modul 8)

Proyek ini adalah pengembangan antarmuka dan logika aplikasi frontend untuk platform **LoakLokal**, yang berfokus pada pengelolaan data dinamis, pencarian produk secara *real-time*, filter kategori, serta validasi form interaktif.

## 🚀 Fitur Utama (Modul 8)
1. **Arsitektur Data Dinamis & Database:** Mengimplementasikan pengelolaan data produk dan transaksi yang terhubung dengan backend PHP dan database.
2. **Pencarian Real-Time & Filter Kategori:** Fitur pencarian barang secara instan serta penyaringan produk berdasarkan kategori.
3. **Form Interaktif & Validasi:** Formulir pengajuan dan transaksi yang dilengkapi dengan validasi input data serta penanganan kondisi kosong (*Empty States*).
4. **Manajemen Git Branch & Kolaborasi:** Pengerjaan fitur diisolasi menggunakan branch khusus `feat/dynamic-data` sebelum diintegrasikan ke branch deployment utama tim.
